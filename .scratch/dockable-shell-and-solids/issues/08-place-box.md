# 08 — 单击放置长方体

**What to build:** 3D 工具箱增加长方体。单击落下默认 1×1×1（看起来像正方体），位置是底面中心，高沿 +Y，三个欧拉角为 0。可与体素写在同一份 3D 说明书里。属性面板能改长宽高和位置。视口能看见。Prompt、打开/保存、分享链接打通。本票不做参数体的视口手柄（见 11）。

**Blocked by:** 03 — 工具箱：图标+名称
