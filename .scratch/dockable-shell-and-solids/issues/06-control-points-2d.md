# 06 — 2D 控制点与命中顺序

**What to build:** 选中 2D 图元后同时显示控制点（端点、圆心、半径点、弧的起止角、多边形/折线顶点）。拖控制点只改那一处几何。命中顺序：控制点优先于旋转/缩放柄，再才是拖本体平移。悬停时光标跟着变。体素与 3D 不在本票。

**Blocked by:** 05 — 2D 旋转/缩放手柄与椭圆旋转角

**Status:** ready-for-agent

- [ ] 各 2D 类型在选中后露出对应控制点，拖动预览后一次提交
- [ ] 拖半径只改半径，不会变成整圆非等比缩放
- [ ] 命中顺序：控制点 → 旋转/缩放柄 → 本体
- [ ] 悬停控制点、柄、本体时光标可区分
- [ ] 属性面板数字与控制点写入同一份说明书
