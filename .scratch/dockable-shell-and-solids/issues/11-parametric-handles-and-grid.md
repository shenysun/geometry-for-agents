# 11 — 参数体变换手柄、控制点与格

**What to build:** 选中 3D 参数体后出现变换手柄与控制点（长宽高、半径、高、底面点等）。命中顺序与 2D 相同：控制点 → 旋转/缩放柄 → 拖本体平移。旋转写入 `rotationDegY/X/Z`，顺序 Y→X→Z。参数体与 2D 一样吃当前格（1 / 1/2 / 关）；Alt 对参数体有效。体素仍整格平移、锁整数、无手柄。
