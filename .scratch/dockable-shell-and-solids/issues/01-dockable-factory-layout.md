# 01 — 可停靠五块面板出厂布局

**What to build:** 操作员打开编辑器看到 Unity 式分块壳：五块可拖拽停靠的面板，出厂为左上工具箱、左下对象列表、中视口、右上属性面板、右下垫图。顶栏（空间、文件、撤销、格、分享、语言）不进停靠区。属性面板只展示当前选中图元；垫图从属性列拆出；JSON 原文不再占属性区。只能在停靠区内并排、改大小、叠标签，没有浮窗、没有弹出浏览器窗口。工具箱这一期可以先是空的可停靠槽（创建工具仍可暂时留在顶栏），只要五块都能拖。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 接入 `dockview-vue`，五块面板可并排、改大小、叠成标签
- [ ] 出厂摆法为左工具箱/对象列表、中视口、右属性/垫图
- [ ] 顶栏不进停靠区；无页内浮窗、无弹出浏览器窗口
- [ ] 属性面板只显示选中图元字段，未选中为空；垫图独立；JSON 原文离开属性面板
- [ ] 视口仍能画、对象列表仍能点选；说明书与分享链接行为不变
