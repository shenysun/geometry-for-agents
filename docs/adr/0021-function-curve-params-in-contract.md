# 函数曲线参数进契约，滑块不立图元

审计缺口 #2（docs/research-math-coverage.md 差距 #5/6）要一次/二次/反比例函数 + 参数滑块。GeoGebra 的滑块是独立对象，可驱动多条曲线；本工具若跟进就需要跨图元引用/依赖层——那是约束层（缺口 #4）的领土。且函数图像的几何身份就是参数在世界坐标下的像：给它锚点、包围盒或整体平移，会把「函数图像」变成「平移后的曲线」，破坏 y=f(x) 身份。

决定：单一图元 `functionCurve`，discriminated union 以 `kind` 取 linear/quadratic/inverse，参数字段直接进契约——区别于 ADR 0017/0020 的「推导值不进契约」：函数参数是形状定义真源，不是标注推导值。坐标系隐式用世界坐标（Y 向上，ADR 0003），不建坐标轴图元，审计缺口 #7 不成本期依赖。曲线无锚点、无控制点、不可拖动；选中后经属性面板滑块与视口浮动条改参数，两处 UI 写同一份契约字段。滑块不做独立图元、不做跨曲线共享，GeoGebra 式 slider 明确排除。第一期仅三种规范参数形式，无自由表达式解析器；三角/指对幂是后续加 kind 枚举值的增量，届时仍走参数形式。创建为单击手势（单击位置不落任何几何），画完即回选择（ADR 0018）。退化取值沿一形一表（ADR 0017）refine 拒绝：linear `a=0`（水平线归 line）、quadratic `a=0`（降为一次函数）、inverse `k=0`（无定义）；属性面板输入退化值报内联校验错误并保留旧值，文案指明替代路径，不静默钳制。三种函数是三个独立工具（一次函数 Shift+L／二次函数 Q／反比例函数 H，键位表见 ADR 0018），kind 决策放在创建前——单工具后切换会把「错误的 kind」写进说明书并复杂化 undo；kind 由创建时的工具定死，事后不改（改 kind 等于换图元，删了重画），属性面板里 kind 只读。曲线只画视口可见 x 范围，随平移缩放实时重算，无自身包围盒；反比例在 x=0 按符号分两段，不跨渐近线连线，渐近线本身不画；采样密度以屏幕空间为准（2px/点），平滑度恒定且每帧采样点数有上界。
