# 参数形一形一表

2D 扩容（矩形之后：三角形、平行四边形、梯形、正多边形、角、尺寸标注线）会让同一形状出现多种表达：平四斜移为零即矩形、梯形上下底等长即平四或矩形、正多边形 3/4 边即等边三角形或正方形。说明书是唯一真源，下游 Agent 要做图形身份判断（割补课件），方言会把归一化成本下沉给 Agent。

决定：参数形之间互不重叠——每个类型用 refine 排除与更基本类型同形的退化取值（平四 `skew ≠ 0`、梯形 `topWidth > 0` 且 `≠ width`、正多边形 `sides ≥ 5`）；与 polygon 的重叠不禁，polygon 是任意形状的逃逸通道，高频形状用参数形是约定；特例不设类型（正方形、菱形、等腰/直角/等边等都是参数取值或工具约束）。底/高家族（三角、平四、梯）锚点取底边中点，沿 3D 站立体底面中心先例；旋转一律绕锚点。数字不进契约：角的度数、标注线的距离都是几何推导值。代价：手势提交时需把退化取值钳制（预览态可自由过零，沿 ADR 0007 预览后提交）。
