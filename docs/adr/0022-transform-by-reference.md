# 变换走引用式，像不进契约

平移/旋转/轴对称/位似（审计缺口 #3，docs/research-math-coverage.md 差距 #10）。两条路线：引用式新图元（像由渲染推导，源动像动，先例 overlapFill/measure）vs 烘焙式工具（提交瞬间生成普通图元，先例拆分）。教学核心价值是关系表达与动态跟随——拖源验证轴对称性质、将军饮马的动态对称轴——烘焙给不了跟随；引用式的像不可独立编辑是与重叠填充一致的已知代价。todo 原把「旋转、翻折等时间轴」合并考虑：仓库无任何动画底子，动态性由参数滑块承担（0021 先例），时间轴/播放器摘出回 todo，属步骤/回放概念层。

决定：新图元 `transform`，discriminated union 以 `kind` 取 translate/rotate/reflect/dilate。变换参数是形状定义真源、直接进契约（同 0021 函数参数，区别于 0020 的推导值不进契约）：translate `{dx,dy}`、rotate `{centerX,centerY,angleDeg}`（正为逆时针，负值存储、显示归一 0–360）、reflect `{x1,y1,x2,y2}`、dilate `{centerX,centerY,ratio}`。退化取值（像与源重合或无定义）沿一形一表（0017）拒绝：平移零向量、旋转 0° 及 ±360° 整倍数、轴对称轴两点重合（退化轴 NaN 无定义）、位似比 0 或 1；比允许负数（负比=中心对称+位似）。对称轴内嵌两点、不引用 line 图元——引用 line 引入第二种引用语义（轴被删/被拖的连锁）与引用套引用。源白名单 `transformable2dTypes`（仿 `measurable2dTypes`，穷尽检查）：2D 笔画族+封闭族+点名；函数曲线被拒（y=f(x) 世界坐标身份与平移像冲突，0021），引用型（重叠填充/度量标注/transform 自身）被拒（引用的引用）；3D 不做（同 0019/0020）。像与辅助几何（轴虚线、中心点）由渲染层画出，不进说明书；像画法固定推导（描边虚线化、填充半透明），不设 style 字段；点名的像锚点照变换、字形不旋转不缩放。命中：点像=选中变换图元（measure 先例），未选中时轴/中心不响应命中（不抢源的点击），选中后轴端点/中心为控制点；级联仅「源被删→变换删」单向。四个创建工具归「特殊」组（M 平移／E 旋转／Shift+M 轴对称／Shift+E 位似，键位表见 0018），kind 由创建工具定死、事后不改。创建两步手势（ADR 0007 预览-提交、0018 画完即回）：先点源锁定（类型拒绝即时反馈），再手势定参——平移拖一向量、旋转点中心（角度默认 90°）、轴对称点两点定轴（点中现成线段图元直接取其两端点为轴）、位似点中心（比默认 2），默认值事后属性面板调；角度与比走滑块（复用函数曲线 preview/release 骨架，松手一步 undo），视口浮动条不做。Prompt 投影是个别化句子（functionCurve 先例），每变换一条，写明像几何是推导非存储。对应点标注（A→A′ 箭头）明确不做，回 todo 与对应关系语义同列。
