# 画完即回选择，配单键工具快捷键

单次完成的创建工具（2D 全部图元与 3D 参数体）提交成功后自动切回选择工具，刚画的图元保持选中，可立即拖动或改控制点；取消或无效提交不动工具。3D 体素例外：连续刷格子的场景保持粘性，同 Unity Tilemap 笔刷惯例。连续绘制不设修饰键、不设锁定模式——想再画一个就再按一次快捷键，重入成本一次按键，换来工具系统少一个状态分支。

选 Figma 的画完即回而非 Unity 的粘性，依据 `docs/research-tool-switch-ux.md`：Unity 实为粘性工具，其流畅感来自 QWERTY 单键快捷键与 Alt 弹簧导航，而"画完必须手点选择工具"恰是粘性之痛。故本编辑器取两者组合：Figma 的行为 + Unity 的手感。

## 键位表

规则：单键给高频工具，Shift+键给同族变体。输入框/文字编辑中不触发；只切当前空间里存在的工具；Alt 保持"临时不落格"职责不变。

- 2D：**V** 选择；**L** 直线；**R** 矩形；**Shift+R** 正方形；**O** 椭圆；**C** 圆；**Shift+C** 圆环；**A** 弧；**Shift+A** 弓；**S** 扇形；**T** 文字；**Shift+T** 三角形；**D** 尺寸标注线；**G** 角；**P** 折线多边形；**Shift+P** 平行四边形；**N** 正多边形；**Z** 梯形。
- 3D：**B** 体素；**Shift+B** 长方体。圆柱、圆锥、球、四棱锥、三棱柱低频，不设键，点工具箱。
