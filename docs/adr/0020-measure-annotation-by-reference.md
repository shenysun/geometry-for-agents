# 度量标注引用式，数值永不进契约

角度度数显示与面积/周长标注（审计 docs/research-math-coverage.md 的最高杠杆缺口）沿两条既有先例落地：角图元加 showDeg 布尔开关，度数本身仍是渲染期推导值（ADR 0017「数字不进契约」的延伸）；新图元 measure 持 {sourceId, kind} 引用一个封闭图元（ADR 0019 引用式先例），无自身坐标——面积显示在源形心、周长在源包围盒上方，跟随源重绘，源删除级联删除。为可拖偏移留向后兼容增量（offset 缺省 0,0），第一期不做。

决定：measure 的源白名单排除 overlapFill。它的交集是渲染期离屏像素合成（source-in 遮罩），无几何表达——面积只能像素计数（随分辨率抖动，两位小数不稳定）或引入 Clipper2 曲边离散近似管线。其余 11 种封闭图元的面积/周长全部有解析公式，零近似。为一个源引入整条近似管线与「推导数值层轻量落地」的主旨不符；白名单排除是可逆增量，几何求交能力落地后再开放。
