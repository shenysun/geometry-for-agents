# 常见数学内容覆盖度审计

- 日期：2026-09-17
- 范围：对照中小学数学课程与主流互动课件平台，审计本工具对常见数学内容的覆盖
- 方法：双代理并行——一者盘点仓库实际支持的数学内容（schema 源：`src/document/parse-document.ts`，工具源：`src/components/toolbox.ts`），一者查证外部基准（课标 + 课件平台）
- 本文性质：**差距审计，不是实施计划**。缺口取舍与优先级决策见 `docs/todo.md`，本文只提供依据。

## 1. 结论摘要（先读这一节）

当前工具是**纯静态几何画板**：小学–初中的「基本图形认识」覆盖良好（2D 17 种图元、3D 7 种立体），但函数、数值度量、变换、约束、动画交互、高中内容基本全缺。最高杠杆缺口是**度量数值层**——架构上已有先例（`angle` 度数与 `dimension` 距离都是渲染期推导值），扩展角度/面积/周长标注可一次性解锁内角和探究、勾股验证、动态度量等核心课件场景。

对照基准：课标「图形与几何」主线 + GeoGebra/希沃/B 站课件库出现频率 + 互动课件对「可拖动、可参数化」表达的依赖程度。

## 2. 现有覆盖（盘点结果）

### 2D 图元（17 种）

- 笔画族：折线、角（弧标，度数不显示）、尺寸标注线（仅两点距离）、弧、点名
- 封闭填充族：多边形、矩形、三角形（底/高/顶点偏移）、平行四边形、梯形、正多边形（边数 ≥5）、圆、扇形、弓形、圆环、椭圆
- 引用条目：重叠填充（两源交集阴影，ADR 0019）

### 3D 图元（7 种）

体素、长方体、圆柱、圆锥、球、四棱锥、三棱柱。

### 度量与约束

- 度量：仅「两点距离」一种（`dimension`，渲染期推导，两位小数）；角度数值、面积、周长、坐标读出全缺
- 约束：仅重叠填充的交集引用；图元间零几何约束，全部自由摆放

### 交互

拖动、控制点手柄、网格吸附、平移缩放、垫图；无变换图元、无动画、无参数驱动。

## 4. 缺口归类（按投入产出排序）

1. **度量数值层**：角度度数、面积、周长标注。现有图元几乎不动，只加推导标注；架构先例是 `angle` 度数（推导值不进契约）与 `dimension` 距离（`toFixed(2)` 去尾零）。解锁 #1/2/3/9 核心场景。工具箱「度量与标注」组已就位（2026-09 分组落地），新条目名正言顺。
2. **函数曲线图元**：一次/二次/反比例（+ 高中三角/指对幂）+ 参数滑块。全新能力线，解锁 #5/6/14。
3. **变换图元**：平移/旋转/轴对称/位似。解锁 #10 及初中经典动态题（将军饮马、折叠）。
4. **约束/关系层**：垂直/相切/中点等。当前图元间零约束全靠手摆，精度受限。
5. **3D 进阶与动画**：棱台/圆台/截面/展开图、步骤分解/回放。量大，优先级靠后。
